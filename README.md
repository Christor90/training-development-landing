
# Training and Development Landing Page

A production-ready Next.js landing page for a training and development company, built with TypeScript, Tailwind CSS, and Lucide React icons and React-icons.


Live URL: https://training-development-landing.vercel.app/

## Features

- Pixel-perfect Figma design implementation
- Fully responsive (mobile, tablet, desktop)
- TypeScript for type safety
- Tailwind CSS for styling
- Lucide React icons
- Semantic HTML & accessibility
- Next.js 14+ with App Router
- Optimized images via next/image

## Tech Stack

- **Framework:** Next.js 14+
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React, React icons
- **Deployment:** Vercel
- **Package Manager:** npm

## Setup & Installation

```bash
# Clone repository
git clone https://github.com/Christor90/training-development-landing.git

# Install dependencies
npm install

# Run development server
npm run dev

# Open in browser
# http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```

## Responsive Breakpoints

- **Mobile:** 425px (sm)
- **Tablet:** 768px (md)
- **Desktop:** 1280px+ (lg)
